Both H2 epics sit on the Bookings team, so this is a real order and not a preference. Åsa picked
no-show fees ([[tickets/jira/BOK-300]]) first, for Q4, and waitlist ([[tickets/jira/BOK-260]])
after it.

The case for fees first is that December no-shows are the top complaint from chains, and
December has a date attached that we did not choose. The waitlist only pays off once tables
free up early, and a fee is what makes a guest cancel instead of not turning up. So the order is
also the order the two features work in.

One team, two epics, and whichever moves second lands a full quarter later. So Q4 for waitlist
means Q4, not "late Q3 if things go well". That is the sentence I need to keep saying out loud
to sales.

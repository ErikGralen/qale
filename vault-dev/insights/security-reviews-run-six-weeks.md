Bergman & Falk run a questionnaire, then evidence collection, then a review board, and the
whole run takes about six weeks. Elin gave the number in the first minute of the kickoff,
"Six weeks if nothing surprising turns up", and was clear that anything unexpected adds more.
One account so far, so it's a working number rather than a rule.

The practical version for sales: an enterprise deal that hasn't entered security review by the
middle of the quarter is not closing that quarter, however keen the buyer sounds on the call.

# Offline mode

The ask is a Rota that keeps working with no connection — a manager editing next week's
schedule in a stockroom, a staff member checking their shift on the underground.

Declined twice, in February and again in May
([[decisions/2026-02-12-decline-offline-mode]]). The reasoning has not moved. Back offices have
wifi; the staff app already caches the schedule for reading, which covers the underground case
that people actually describe; and offline *writing* means conflict resolution on a shared
schedule, which is the expensive half nobody is asking for. Two managers editing the same week
offline and reconciling later is a bug factory.

It comes back through sales rather than through customers, usually as a line on a prospect's
requirements list rather than a described problem ([[people/marcus-ek]]). When we have unpicked
it, the real question has been "what happens if the wifi drops mid-edit", which is a
save-and-retry answer, not an offline-mode answer.

This file exists so the third ask is cheap to answer. If a real chain ever loses connectivity in
a way that costs them a schedule, reopen it with that account named.

# Changelog

What changed in Bord, newest first. This page is public.

## 2026-06-24

Bookings taken by phone now show in the same list as online bookings. One list for the
evening, whatever the source.

## 2026-05-12

Book a table from Google. Guests can book from your restaurant's Google listing with a "Book a
table" button. Switch it on under Settings, Booking channels.

## 2026-04-02

One reminder, the day before. Guests get one text reminder for a booking, the day before at
17:00.
